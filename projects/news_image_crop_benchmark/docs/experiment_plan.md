# 实验计划

## Benchmark 核心问题

Qwen3.5-9B 能否根据新闻标题和原图生成有用的固定比例裁剪？GRPO 能否使裁剪质量优于确定性基线？

本项目首先建立自动化 proxy benchmark。在对产品质量作出结论之前，必须在小规模、独立保留的人工 golden set 上进行偏好评测。

## 数据集构建

1. 审计源 Parquet，并保留不可变的源数据行标识。
2. 按 `OriginalImageUrl` 对图片存储去重，同时保留标题不同的样本行。
3. 将 `OriginalImageBytes` 提取为共享图片文件，避免 verl 反复把 3.1 GB 二进制列加载到 driver 内存。
4. `CroppedImageUrl` 和 `Reason` 都不能与标题可靠配对，因此只保留在原始审计索引中。
5. 对完全相同的标题/原图组合去重，然后将每个组合展开为比例 `1.0`、`1.91`、`1.77` 和 `1.59` 的四个任务。
6. 按 `OriginalImageUrl` 而不是按行进行 80/10/10 划分。
7. 写出 verl 可用的 Parquet，只包含标题、原图路径、目标比例、prompt 和评测元数据。

训练数据和 Reward 数据不得包含未配对的裁剪 URL 或原因文本。

## 实验阶段

### P0：数据与 Reward 验证

- 对 100 条多样化样本运行完整转换流程。
- 覆盖全部四种比例，渲染并检查至少 30 个生成任务。
- 根据视觉检查和人工 golden set 校准 proxy 指标，不使用原始 `Reason`。
- 确认 Reward 支持批处理并且结果具有确定性。

### P1：基线

- 满足目标比例约束的中心裁剪。
- 基于显著性/grounding proposals 的自动启发式裁剪。
- Qwen3.5-9B zero-shot 裁剪动作。

正式训练前必须先运行未训练 Qwen3.5-9B 的 vLLM baseline。至少按“原图+标题”抽取若干组完整四比例任务，每个 prompt 采样多个候选，记录格式合法率、动作面积/中心分布、proxy reward，以及 best-of-N 相对中心裁剪的胜率。Baseline 结果固定后再启动 GRPO，避免只看到训练后分数而无法判断实际增益。

完整的两阶段规模、对照组、`pass@1/mean@8/best@8` 报告要求、人工抽查和决策门槛见 [baseline_evaluation.md](baseline_evaluation.md)。该文档是 P1 的验收依据。

### P2：自动伪标签 SFT

- 围绕显著区域和标题相关区域生成满足比例约束的候选框。
- 使用冻结的 proxy reward 对候选框排序。
- 仅训练到足以稳定输出 `<crop>` 协议并形成有效探索为止。

伪 SFT 标签属于弱监督，不得作为最终评测目标。

### P3：GRPO

- 每个 prompt 采样 8 个策略动作。
- 将动作转换为严格满足目标比例且不越界的 bbox。
- 渲染裁剪图，并使用冻结的 Reward adapter 评分。
- 分别记录每个 Reward 分项、非法率、动作面积和裁剪中心分布。
- 如果 Reward 上升但 held-out proxy 或视觉质量没有改善，则判定该次实验无效。

### P4：扩展与质量评测

- 只有在 P3 正确性验收通过后，才从单个 8 GPU 节点继续扩展。
- 从保留测试集中构建 300 条人工 golden set。
- 将候选结果与生产裁剪、中心裁剪、启发式裁剪和 zero-shot 裁剪进行两两比较。

## 评测指标

工程指标：

- bbox 解析成功率/合法率；
- 严格宽高比和不越界比例；
- rollout 和训练吞吐量；
- GPU/CPU 峰值内存；
- 每个候选框的 Reward 延迟；
- checkpoint 保存与恢复的正确性。

Proxy 质量指标：

- 标题相关性；
- 主体完整性；
- 显著区域保留率；
- 人脸/OCR 完整性；
- 构图和美学得分；
- 相对每个自动基线的胜率。

最终质量指标：

- 人工两两比较的胜/平/负比例；
- 不可接受裁剪比例；
- 标注者间一致性；
- 按目标比例和失败类型拆分的结果。

## 初始验收条件

- 伪 SFT 后至少 95% 的策略输出合法。
- 100% 的渲染裁剪框不越界并满足目标宽高比。
- 四种比例全部存在，并且每组原图只属于一个 split。
- GRPO 在 held-out proxy 指标上必须优于 zero-shot 和启发式基线。
- 在报告人工胜率置信区间之前，不得宣称达到产品质量。
